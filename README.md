# Неоновая арена

Сетевой шутер с видом сверху на чистой Java, без сторонних библиотек.
До 4 игроков по локальной сети, боты с поиском пути, бонусы, лента событий и таблица счёта.

## Запуск

**В IntelliJ IDEA:** `File → Open` → выбрать папку `neon-arena` (IDEA увидит `pom.xml`) →
открыть `src/main/java/arena/Main.java` → зелёная стрелка у `main`.

**Без IDE:** двойной клик по `run.cmd`. Скрипт сам найдёт JDK (подойдёт тот, что скачала IntelliJ), соберёт `arena.jar` и запустит игру.

| Файл | Что делает |
|---|---|
| `run.cmd` | собрать и запустить игру |
| `build.cmd` | только собрать `arena.jar` |
| `server.cmd [порт] [боты]` | сервер без окна, например `server.cmd 7777 2` |

## Как играть с другом

1. **Хост** нажимает «Создать игру». В правом верхнем углу появится адрес вида `192.168.0.5:7777`.
2. Windows спросит про брандмауэр — разрешить доступ для **частных сетей**.
3. **Друг** выбирает «Подключиться к другу» и вводит этот адрес.

Нужно быть в одной сети (один Wi-Fi). Через интернет — либо пробросить порт 7777 на роутере хоста,
либо поставить обоим программу виртуальной локальной сети (Radmin VPN, ZeroTier) и использовать её адрес.

**Проверить одному:** запусти `run.cmd` два раза. В первом окне — «Создать игру», во втором — «Подключиться» к `127.0.0.1`.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| мышь | прицел |
| ЛКМ / пробел | огонь |
| Tab (держать) | таблица счёта |
| Esc | выход |

Бонусы: 🟩 аптечка (+40 HP), 🟨 скорострельность ×2.5, 🟦 ускорение. Действуют 6 секунд.

## Как это устроено

```
 Клиент                                Сервер (авторитарный)
 ──────                                ─────────────────────
 InputHandler ── кнопки + угол ──▶     ClientConnection (поток чтения)
   60 раз/с      (Message.Input)              │
                                              ▼
                                       World.update() — 60 тиков/с:
                                       движение, пули, попадания, бонусы, боты
                                              │
 SnapshotBuffer ◀── снимок мира ──     ClientConnection (поток записи)
   интерполяция    (Message.State)
       │
       ▼
 Renderer — рисует кадр (до 120 кадров/с)
```

- **Сервер решает всё.** Клиент присылает только нажатые кнопки, а куда сдвинулся корабль и кто в кого попал,
  считает сервер. Поэтому подправить свои координаты в клиенте не выйдет.
- **Протокол** (`Protocol.java`): каждый пакет — это `[длина][тип][данные]`. Длина нужна потому,
  что TCP — сплошной поток байтов без границ между сообщениями.
- **Интерполяция** (`SnapshotBuffer.java`): клиент показывает мир на 50 мс «в прошлом»
  и плавно смешивает два соседних снимка. Без неё всё дёргалось бы от неровной доставки пакетов.
- **Боты** (`BotBrain.java`) ищут путь поиском в ширину (BFS) по сетке тайлов и «нажимают» те же кнопки, что и человек.
  Когда заходит живой игрок, бот освобождает ему место.

```
src/main/java/arena/
├── Main.java            точка входа
├── common/              общее для клиента и сервера
│   ├── Config.java      все числа игры — крути их!
│   ├── GameMap.java     карта, столкновения со стенами, линия видимости
│   ├── Message.java     виды сетевых сообщений
│   ├── Protocol.java    сообщения ⇄ байты
│   └── Snapshot.java    снимок мира
├── server/              GameServer, ClientConnection, World, BotBrain…
└── client/              Launcher, GameWindow, GameClient, SnapshotBuffer, Renderer, InputHandler
```

Карта задаётся строками прямо в `GameMap.java`: `#` — стена, `S` — точка появления,
`H` — аптечка, `R` — скорострельность, `V` — ускорение. Нарисуй свою!

## Что можно добавить самому

1. **Предсказание на клиенте** (client-side prediction): сейчас свой корабль двигается с задержкой примерно 50 мс плюс пинг.
   Можно двигать его сразу, а потом сверяться с сервером. Это классическая задача сетевых игр.
2. **Новое оружие:** дробовик (несколько пуль веером), ракеты с уроном по площади.
3. **Карты из файлов** и выбор карты в окне запуска.
4. **Чат:** новое сообщение `Message.Chat` и поле ввода по Enter.
5. **Звуки** выстрелов и взрывов через `javax.sound.sampled`.
6. **Режимы игры:** командный бой, игра до 10 побед с таймером.
7. **Тесты на JUnit 5** для `World` и `Protocol`.
